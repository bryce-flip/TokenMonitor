<objective>
Tracer: one continuous, checkpointed ingest path through every layer this phase touches.

**As an** operator, **I want** the indexer to continuously maintain event history I can trust across RPC failures, restarts, duplicate reads, and short chain reorganizations, **so that** stored figures stay traceable to canonical events without manual babysitting. (User story derived verbatim in substance from the ROADMAP Phase 2 goal; the user delegated phase decisions to Claude on 2026-10-09.)

This plan delivers the thinnest end-to-end slice: config(head_policy) -> eligible-head resolution -> durable (height, hash) checkpoint -> continuous bounded window loop with advance-after-accept ordering -> crash-safe resume -> FINAL-idempotent replay proof. Plans 02-02 and 02-03 harden the slice (failure discrimination, reorg rewind) without changing its shape.

Purpose: SYNC-01 (bounded ranges advance only through the configured head, continuously), SYNC-03 (durable checkpoint that advances only after events are durably accepted), SYNC-04 (replay changes nothing, even pre-merge). Implements D-01 (finalized default, confirmed option) and D-04 (checkpoint resume, start_block opt-in).
Output: a running `cmd/indexer run` that survives restarts and replays, plus the offline and ClickHouse-integration proofs.
</objective>
