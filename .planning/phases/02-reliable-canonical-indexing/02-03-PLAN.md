Collect before-totals (RangeTotals from rewind point + 1 to checkpoint height), print/return the plan; if !opts.Yes the CLI prompts (the function itself performs the destructive steps only when opts.Yes or when invoked non-interactively by the CLI after confirmation — put the prompt in the CLI, keep Rewind pure given confirmed opts).

       g. rs.WriteCheckpoint(chain, rewindPoint, canonicalHashAt(rewindPoint)) — re-anchor.
